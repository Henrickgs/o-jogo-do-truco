# Truco Arena — início do projeto

## Publicar no GitHub Pages
1. Entre em https://github.com e faça login.
2. Clique em **New repository** e dê o nome `truco-arena`.
3. Escolha **Public** e crie o repositório.
4. Use **Add file → Upload files** e envie `index.html` e a pasta `supabase`.
5. Clique em **Commit changes**.
6. Vá a **Settings → Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**.
8. Selecione `main` e `/ (root)`, depois clique em **Save**.
9. O GitHub exibirá o endereço público do site.

## Estado atual
Esta entrega contém a tela inicial responsiva e um esqueleto SQL do banco. Os botões mostram avisos de funcionalidades ainda em desenvolvimento. Login Google/e-mail, salas, multiplayer em tempo real, ranking e partidas completas ainda não estão ativos.
